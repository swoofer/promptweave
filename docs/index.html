promptweave

YAML composer for assembling agent prompts, hooks, and MCP configs from reusable behaviors.

Quick start

npm install -g promptweave
promptweave list behaviors
promptweave build inspect --dry-run

Why

Hand-writing agent prompts gets messy fast. You end up copy-pasting the same coordination rules, hook scripts, and MCP configs across every agent profile. promptweave lets you write each behavior once as a small YAML, then compose them into presets — the engine assembles a deterministic prompt, hooks per lifecycle, an `.mcp.json`, and env vars.

Use cases

  • Version-controlled agent profiles for Claude Code, Cursor, Aider, custom agents.
  • Shared behavior catalog across a dev team — one source of truth for prompts/hooks/MCP configs.
  • CI-enforced consistency of agent assemblies.
